# TreeQt v0.1.1

First public binary release of TreeQt for Linux x86_64.

## Included assets

- `TreeQt-x86_64.AppImage` — portable application image
- `TreeQt-linux-x86_64.tar.gz` — user-local installer package
- `SHA256SUMS` — release integrity hashes
- `QT_VERSION.txt` — Qt runtime build version

## Current capabilities

- scan a filesystem tree
- display directories and files in a Qt5 tree view
- queue move and copy operations
- rename files and directories
- create directories
- queue deletion
- undo or clear queued operations before commit
- basic pre-execution validation
- apply queued filesystem changes only when **Finish** is pressed

## Important

TreeQt v0.1.1 is early software. Test destructive filesystem operations on disposable data first and maintain backups.

The application source code is not distributed from the public repository.
